# RestaurantMom

A personal agent that remembers every dish you've ordered and how it went, so you never
order the bad French dip twice. Built at Build Personal Agents Hack, Oct 4 2026.

## Stack
- **Mastra** agent + tools (`src/mastra`)
- **Neon** Postgres (history) and AI Gateway (model calls)
- **Exa** menu + review research for places you've never been
- **assistant-ui** chat front end (Next.js), **Fly.io** hosting

## Layout
```
src/mastra/        agent, tools, db helper        (written)
src/app/api/chat/  streams the agent to the UI    (written)
schema.sql         Neon tables + demo seed data   (written)
src/app/page.tsx, components/assistant-ui/*       generated by `assistant-ui init`
```

## One-time setup (needs npm access)

Generate the Next.js + assistant-ui shell in a sibling folder, then merge it into this repo:

```bash
# from the folder that CONTAINS your clone of this repo
npx create-next-app@latest mom-app --ts --tailwind --app --src-dir --eslint --use-npm --import-alias "@/*" --yes
cd mom-app
npx assistant-ui@latest init            # answer prompts; adds the Thread UI + runtime wiring
npm i @mastra/core @mastra/ai-sdk zod @neondatabase/serverless
cd ..

rsync -a --exclude node_modules --exclude .git --exclude README.md mom-app/ RestaurantMom/
cd RestaurantMom && npm install
```

Then:
1. In `next.config.*` add `serverExternalPackages: ["@mastra/*"]` to the config object.
2. Run `npm ls ai`. If the major isn't 6, change `AI_SDK_STREAM_VERSION` in
   `src/app/api/chat/route.ts` to match (`'v7'` for ai 7.x).
3. In the assistant-ui runtime file the CLI generated (usually `src/app/assistant.tsx`),
   make sure the transport points at `/api/chat`:
   `new AssistantChatTransport({ api: "/api/chat" })`
4. `cp .env.example .env.local` and fill it in.
5. Load the schema: paste `schema.sql` into the Neon SQL editor (or `psql "$DATABASE_URL" -f schema.sql`).
6. `npm run dev` and open http://localhost:3000.

## Smoke tests (in the chat)
1. "I'm at Harrison Street Deli" -> warns off the French dip, pushes the pastrami
2. "Thinking about a French dip at Golden Gate Grill" -> calls out the pattern
3. "Just had the al pastor at Taqueria Luz, solid 4, nice char" -> logs it
4. "I'm going to <real SF place>" -> Exa research + taste-based pick

Demo data uses fictional restaurant names on purpose.
